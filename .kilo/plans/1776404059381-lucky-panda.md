# Plan: Configurar variables de entorno en his-lite-backend

## Problema
La aplicación no inicia porque las variables de entorno de Supabase no están configuradas:
```
Error: supabaseUrl is required
```

## Solución

### Paso 1: Crear archivo .env
Copiar `.env.example` a `.env` con las variables de Supabase:
```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

### Paso 2: Configurar proyecto Supabase
El usuario debe:
1. Crear un proyecto en [supabase.com](https://supabase.com)
2. Obtener la URL y la ANON KEY del proyecto
3. Actualizar el archivo `.env` con estos valores
4. Ejecutar el schema SQL en el editor SQL de Supabase

### Paso 3: Verificar
Ejecutar `npm run dev` y verificar que la app carga correctamente.
